# no-js-framework

Список пользователей: https://dummyjson.com/users/

Приложение: [https://сatorol.github.io/no-js-framework/](https://catorol.github.io/no-js-framework/)

## Инструменты и почему

* **htmx 2.** Запрос, место вставки результата и способ вставки описаны атрибутами в разметке, без собственного JavaScript. В `htmx-config` выставлено `selfRequestsOnly: false`, потому что по умолчанию htmx 2 блокирует запросы на чужие домены.
* **Расширение client-side-templates.** htmx ожидает от сервера HTML, а dummyjson отдаёт JSON. Расширение превращает JSON в HTML прямо в браузере, поэтому писать свой код-преобразователь не нужно.
* **Шаблонизатор Mustache.** Он лёгкий, а его синтаксиса (`{{поле}}`) достаточно для вывода списка. Значения экранируются, поэтому данные из внешнего API не интерпретируются как HTML.

## Как работает

* При открытии страницы виден список из одного элемента «...».
* Кнопка «Загрузить пользователей» содержит `hx-get` с адресом `https://dummyjson.com/users?limit=10&select=...`. По клику htmx отправляет этот запрос. Параметр `limit=10` берёт только первых 10 пользователей, а `select` оставляет только нужные поля: имя, фамилию, отчество, email и пароль.
* Ответ приходит в формате JSON. Атрибут `mustache-template="users-tpl"` указывает шаблон, через который этот JSON превращается в HTML. Шаблон лежит в разметке, в теге `<template id="users-tpl">`. Блок `{{#users}}...{{/users}}` повторяется для каждого пользователя и выводит строку вида `ФИО, email: <email>, password: <password>`.
* Атрибуты `hx-target="#users"` и `hx-swap="innerHTML"` подставляют готовые `<li>` внутрь списка `<ul id="users">` и заменяют заглушку.
